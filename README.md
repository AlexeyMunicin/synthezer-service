# VOXsync

VOXsync — учебный веб-проект для автоматического дубляжа видео: приложение загружает видео по ссылке, распознаёт речь, переводит реплики, синтезирует озвучку и собирает результат с субтитрами.

**Пайплайн:** yt-dlp → Whisper (MLX) → Qwen (MLX) → Edge TTS → FFmpeg.

> Проект рассчитан на локальный запуск на macOS с Apple Silicon. MLX-компоненты не поддерживают обычный запуск на Windows/Linux и требуют ресурсов для загрузки и работы моделей. Для работы нужны доступ в интернет и установленный FFmpeg.

## Возможности

- Регистрация и вход с JWT-аутентификацией.
- Запуск задачи обработки видео и просмотр её статуса.
- История задач пользователя.
- Перевод на настроенные в приложении языки и выбор голоса.
- Выдача готового видео и субтитров WebVTT.

## Требования

- macOS на Apple Silicon (M1 или новее).
- Python 3.11 или новее.
- Node.js 18 или новее и npm.
- FFmpeg, доступный в `PATH`.
- Интернет для скачивания исходного видео и моделей.

Установка FFmpeg через Homebrew:

```bash
brew install ffmpeg
```

## Установка и запуск

Из корня репозитория:

```bash
python3 -m venv .venv
source .venv/bin/activate
python -m pip install --upgrade pip
python -m pip install -r requirements.txt
cp .env.example .env
```

Сгенерируйте собственный секретный ключ и задайте его в `.env` как `SECRET_KEY`. Например, командой:

```bash
python -c 'import secrets; print(secrets.token_urlsafe(32))'
```

Вставьте выведенное значение вместо примера. Не публикуйте `.env` и не используйте один секретный ключ в нескольких проектах.

Установите зависимости интерфейса и соберите его:

```bash
cd frontend
npm ci
npm run build
cd ..
```

Запустите API из корня проекта:

```bash
uvicorn src.api.main:app --reload --port 8000
```

Откройте <http://localhost:8000>. Первый запуск может занять больше времени: MLX загружает модели. Для входа сначала зарегистрируйте пользователя.

Для разработки интерфейса отдельно запустите `npm run dev` из `frontend/`; API должен работать на порту 8000.

## Настройки

| Переменная | Назначение | Значение по умолчанию |
|---|---|---|
| `APP_NAME` | Имя приложения | `VOXSYNC` |
| `DEBUG` | Режим отладки | `false` в примере |
| `SECRET_KEY` | Подпись JWT-токенов; обязательно задать локально | нет |
| `STORAGE_PATH` | Каталог временных и готовых файлов | `./storage` |
| `WHISPER_MODEL` | Модель распознавания: `tiny`, `base`, `small`, `medium`, `large-v3` | `small` в примере |

База SQLite создаётся локально при первом запуске. Хранилище видео, аудио и база данных не предназначены для коммита.

## API

- `POST /api/register` — регистрация (`email`, `password`, form data).
- `POST /api/login` — получение JWT (`email`, `password`, form data).
- `GET /api/me` — текущий пользователь, требуется Bearer-токен.
- `POST /api/process` — запуск дубляжа (`url`, `target_lang`), требуется авторизация.
- `GET /api/status/{job_id}` — статус своей задачи.
- `GET /api/jobs` — история задач текущего пользователя.
- `POST /api/admin/cleanup` — очистка просроченных файлов.

Интерактивная документация FastAPI доступна по адресу <http://localhost:8000/docs>.

## Ограничения

- Обработка требует загрузки видео и моделей; время зависит от длины ролика и ресурсов компьютера.
- Интеграционный сценарий в `tests/test_pipeline.py` скачивает публичное видео и запускает реальные модели, поэтому это не быстрый изолированный unit-тест.
- Фоновые задачи выполняются процессом FastAPI и не сохраняются как очередь при перезапуске сервера.
- Перед обработкой убедитесь, что у вас есть право использовать исходное видео и получившийся дубляж. Соблюдайте условия платформы-источника и используемых сервисов.
- Edge TTS использует сетевой сервис Microsoft; проверьте его актуальные условия использования перед применением.
